# Learning roadmap

| Sequence | Focus | You can do this when… |
|---|---|---|
| 01 | Events, workflow YAML and runner logs | Your push starts a workflow and you can explain a failed step |
| 02 | Jobs, dependencies, data and artifacts | You can select parallel/sequential work and pass a value |
| 03 | Docker in CI | You can build, run, HTTP-check and clean a container |
| 04 | Self-hosted runners | You can isolate, register, label, inspect and remove one |
| 05 | Application CI/CD | Tests and image build run on pushes and pull requests |
| 06 optional | Workflow security | Permissions are minimal and secrets stay out of logs |
| 07 optional | Reuse and releases | A caller reuses a workflow/action and publishes a tagged artifact |

Core estimates total 14–18 hours; optional work adds 4.5–5.5 hours. Allow additional time for setup and repeated practice.
