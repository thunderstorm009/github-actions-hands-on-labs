# Glossary

- **Workflow:** automated process defined by YAML.
- **Event:** activity that starts a workflow, such as `push`.
- **Job:** group of steps scheduled on a runner.
- **Step:** action or shell command in a job.
- **Runner:** machine that executes a job.
- **Action:** reusable unit invoked by `uses`.
- **Artifact:** file preserved and shared between jobs or downloaded after a run.
- **Context:** event/run data exposed to expressions, such as `github.repository`.
- **Secret:** encrypted value exposed to workflow steps when authorized.
- **CI/CD:** continuous integration and delivery/deployment practices.
