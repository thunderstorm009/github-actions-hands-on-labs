# Genuine screenshot guide

Capture these in your own practice repository after performing the lab. Do not recreate or edit GitHub UI images to imply a real run. Store genuine captures here with identifiers removed where appropriate.

Recommended captures: VS Code Explorer with the lab structure; workflow YAML in editor; terminal commands and outputs; personal GitHub repository; Actions workflow run and job graph; an individual step log; successful run; and intentional failure plus repaired run. Labs involving Docker should include `docker ps` and the locally rendered app. Redact tokens, secrets, account emails and private repository information. Add a caption explaining the question the image answers. The conceptual SVGs in `../diagrams/` are not screenshots and prove no execution.
