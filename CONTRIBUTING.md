# Contributing

Thanks for helping learners. Open an issue for inaccurate instructions, broken links or ideas. Fork the repository, clone your fork, create a branch, open the folder in VS Code and make a focused change. Test commands in a disposable practice repository where possible; do not claim execution evidence unless you ran it.

A new lab should follow `docs/templates/LAB-TEMPLATE.md`: duration and breakdown, concepts, architecture, prerequisites, exact paths/commands, complete file contents, expected outputs labeled illustrative, verification, troubleshooting, exercises with hints/solutions, security, cleanup and official further reading. Use a dedicated `images/` directory. Screenshots must be genuine and captioned; placeholders must say they are placeholders. Diagrams should be original Mermaid/SVG. Never include secrets, tokens, private keys or personal data.

Review Markdown links, YAML indentation, workflow permissions and file paths. Run applicable commands in a clean environment. Submit a pull request describing the learner outcome and evidence; screenshots must be redacted. See the [lab template](docs/templates/LAB-TEMPLATE.md).
